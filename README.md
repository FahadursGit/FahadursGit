## 💫 About Me

Hello! I'm **Fahadur Rahman**, an undergraduate student pursuing B.Tech in Artificial Intelligence and Data Science.

I'm passionate about exploring the intersection of Data Science, Artificial Intelligence, and software development. I enjoy working with data, discovering meaningful patterns, experimenting with machine learning models, and developing practical applications that solve real-world problems.

I believe in learning by building, experimenting with new technologies, and continuously improving my technical and problem-solving abilities.

### 🎯 My Professional Interests

- 📊 **Data Science & Analytics:** Data cleaning, exploratory data analysis, data processing, visualization, and extracting actionable insights.
- 🤖 **Artificial Intelligence:** Machine learning, deep learning, computer vision, and AI-powered applications.
- 💻 **Backend Development:** Java, Spring Boot, Python, REST APIs, and database integration.
- 🗄️ **Database Management:** Relational databases, SQL queries, and data management.
- ☁️ **Cloud & Infrastructure:** Exploring cloud technologies, Linux, and Docker.
- 🌏 **International Opportunities:** Interested in Japanese technology, international collaboration, and global career opportunities.
